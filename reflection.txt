1. CSS Grid is a two-dimensional layout system built into CSS that lets you arrange webpage elements into rows and columns at the same time. 
2. Flexbox is one-dimensional and CSS Grid is two-dimensional
3. The grid-template-columns property defines the number and width of columns in a CSS Grid container.
4. A media query is a CSS rule that applies specific styles only when a device or browser window meets certain conditions, such as a minimum or maximum screen width.
